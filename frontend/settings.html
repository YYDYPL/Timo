AI 设置

配置 OpenAI 兼容来源（Base URL + API Key + 模型），一键切换当前使用的 AI 服务。

使用说明

  • 所有来源都用 OpenAI 兼容格式：填写服务的 Base URL、API Key 和模型名。
  • DeepSeek：https://api.deepseek.com、模型如 deepseek-chat。
  • 智谱 GLM：https://open.bigmodel.cn/api/paas/v4。
  • OpenAI：https://api.openai.com/v1。
  • 本地 Ollama：http://localhost:11434/v1，API Key 可留空。
  • 未激活任何来源时，会使用 .env 文件里的 LLM_API_KEY / LLM_BASE_URL / LLM_MODEL。
  • 切换后立即生效，题库、复习、项目追问都会用当前来源。
